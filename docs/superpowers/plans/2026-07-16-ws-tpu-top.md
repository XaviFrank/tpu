# ws_tpu_top (Chip-Level Top) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** First synthesizable module wiring axi_lite_ctrl to ws_quant_unit — one AXI-Lite-controllable accelerator — with the existing integration TB refactored to point at it, verification-preserving.

**Architecture:** `ws_tpu_top` promotes tb_axi_lite_ctrl's DUT-instantiation section to RTL: both instances, direct core-side wiring, w_tile_idx/a_base tied 0, raw write ports + bottom-edge results exposed as top-level ports (future DMA attach points). Parameter coupling becomes structural (one parameter set feeds both instances) plus build-time guards for the register-map packing invariants.

**Tech Stack:** SystemVerilog (Icarus -g2012 via ./regress.sh); existing modules untouched.

## Global Constraints

- Run `./regress.sh` after every RTL or TB change; `=== REGRESSION GREEN ===` + exit 0 required (14 TBs). Standing user consent to run it freely (granted this session).
- New files added to regress.sh's explicit per-TB lists as part of creating them.
- RTL style: dull portable constructs only — no whole-array assigns, no inline sized casts, no expressions in port connections (tied-zero inputs get declared nets); wires shared across generate blocks at module level.
- Reset style: control registers async reset, datapath none. (`ws_tpu_top` adds NO registers — pure wiring + guards.)
- TB conventions: drive negedge / sample posedge, !==/===, "ALL TESTS PASSED" banner.
- §3 is a VERIFICATION-PRESERVING refactor: every PASS line of tb_axi_lite_ctrl must be identical before/after at the default jitter seed (seed 1 makes the run deterministic). Whitebox monitors are re-pointed hierarchically (`dut.core_go`, `dut.core_n_vecs`), never dropped or reworked. If a check cannot be cleanly re-pointed, STOP and flag it.
- `ws_tpu_top` must infer 0 DSPs (noted for the human's Vivado run).
- Spec §2 deviation, locked in during planning: the spec asks for assertions "comparing the relevant parameters" between the two instances; in `ws_tpu_top` both instances take VEC_W/SCALE_WIDTH/SHIFT_WIDTH from the top's single parameter set, so cross-instance drift is impossible by construction. The guards therefore assert the invariants that CAN still break — REQUANT_CFG packing (SCALE_WIDTH+SHIFT_WIDTH+1 ≤ 32) and VEC_W ≤ 32 — via generate/initial + $error/$fatal, which fails the regress build loudly per the spec's intent.
- Never touch vivado/. Commit at every green regression; push after green commits.

## File Structure

- `rtl/ws_tpu_top.sv` (new, Task 1) — the wrapper; internal net names `core_*` match axi_lite_ctrl's port names so TB hierarchical references read naturally.
- `tb/tb_axi_lite_ctrl.sv` (modify, Task 2) — same file, same checks; DUT section becomes one `ws_tpu_top` instance.
- `regress.sh` (modify, Task 2) — add `rtl/ws_tpu_top.sv` to the tb_axi_lite_ctrl list.

- [ ] **Step 1: Write the complete file**

```systemverilog
`timescale 1ns / 1ps
//====================================================================
// ws_tpu_top: chip-level top - the first synthesizable module that
// wires the control plane (axi_lite_ctrl, PS AXI-Lite clock domain)
// to the compute core (ws_quant_unit, core clock domain). This is
// the complete AXI-Lite-controllable accelerator, not separately-
// proven pieces; set it as the Vivado top and both clocks coexist
// for the constraints/timing.xdc clock groups to apply.
//
//   - Register map + host contract: see axi_lite_ctrl's header.
//   - Parameter coupling: both instances take VEC_W / SCALE_WIDTH /
//     SHIFT_WIDTH from THIS module's single parameter set, so the
//     pairing cannot drift by construction. The guards below
//     additionally fail the build (regress) loudly if a parameter
//     edit breaks the 32-bit register-map packing itself.
//   - Single-tile scope: w_tile_idx / a_base tied 0 (no registers in
//     the AXI map yet); first extension point for WS tiling.
//   - Raw buffer write ports and bottom-edge results are top-level
//     ports: the future DMA/AXI-HP attach points (TBs drive them
//     directly today; data movement is NOT AXI-Lite's job).
//   - Pure wiring + guards: zero registers, zero DSPs expected. A
//     DSP appearing here in synth means something got miswired into
//     logic rather than a straight port connection.
//====================================================================
module ws_tpu_top #(
    parameter int N           = 4,
    parameter int K           = 4,
    parameter int DATA_WIDTH  = 8,
    parameter int ACC_WIDTH   = 32,
    parameter int DEPTH       = 64,
    parameter int VEC_W       = 4,
    parameter int OUT_WIDTH   = 8,
    parameter int SCALE_WIDTH = 16,
    parameter int SHIFT_WIDTH = 5
)(
    // AXI-Lite subordinate (PS domain)
    input  logic        s_axi_aclk,
    input  logic        s_axi_aresetn,
    input  logic        s_axi_awvalid,
    output logic        s_axi_awready,
    input  logic [5:0]  s_axi_awaddr,
    input  logic        s_axi_wvalid,
    output logic        s_axi_wready,
    input  logic [31:0] s_axi_wdata,
    input  logic [3:0]  s_axi_wstrb,
    output logic        s_axi_bvalid,
    input  logic        s_axi_bready,
    output logic [1:0]  s_axi_bresp,
    input  logic        s_axi_arvalid,
    output logic        s_axi_arready,
    input  logic [5:0]  s_axi_araddr,
    output logic        s_axi_rvalid,
    input  logic        s_axi_rready,
    output logic [31:0] s_axi_rdata,
    output logic [1:0]  s_axi_rresp,

    // core domain
    input  logic                          core_clk,
    input  logic                          core_rst_n,

    // raw buffer write ports (future DMA/AXI-HP path)
    input  logic                          wr_en_w,
    input  logic [$clog2(DEPTH)-1:0]      wr_addr_w,
    input  logic [N*DATA_WIDTH-1:0]       wr_data_w,
    input  logic                          wr_en_a,
    input  logic [$clog2(DEPTH)-1:0]      wr_addr_a,
    input  logic [N*DATA_WIDTH-1:0]       wr_data_a,

    // perf counter clear (no AXI bit yet - see docs/perf_map.md)
    input  logic                          perf_clear,

    // bottom-edge results (column-skewed; future DMA path)
    output logic signed [ACC_WIDTH-1:0]   sum_out   [N],
    output logic                          sum_valid [N],
    output logic signed [OUT_WIDTH-1:0]   q8_out    [N],
    output logic                          q8_valid  [N]
);

    //----------------------------------------------------------------
    // Register-map contract guards: a parameter edit that breaks the
    // packing the AXI map assumes fails the regress build at time 0
    //----------------------------------------------------------------
    if (SCALE_WIDTH + SHIFT_WIDTH + 1 > 32) begin : gen_cfg_pack_guard
        initial begin
            $error("ws_tpu_top: REQUANT_CFG packing (%0d bits) does not fit one 32-bit register",
                   SCALE_WIDTH + SHIFT_WIDTH + 1);
            $fatal(1);
        end
    end

    if (VEC_W > 32) begin : gen_vecw_guard
        initial begin
            $error("ws_tpu_top: VEC_W (%0d) exceeds the 32-bit N_VECS register", VEC_W);
            $fatal(1);
        end
    end

    //----------------------------------------------------------------
    // Control plane <-> core wiring. Net names match axi_lite_ctrl's
    // core-side port names: TB whitebox monitors reference
    // dut.core_go / dut.core_n_vecs - do not rename.
    //----------------------------------------------------------------
    logic                          core_go, core_busy;
    logic [VEC_W-1:0]              core_n_vecs;
    logic                          core_relu_en;
    logic signed [SCALE_WIDTH-1:0] core_scale_mult;
    logic [SHIFT_WIDTH-1:0]        core_shift_amt;
    logic [3:0]                    core_perf_addr;
    logic [31:0]                   core_perf_data;

    // single-tile scope: tile index / activation base tied 0
    logic [$clog2(DEPTH/K)-1:0]    tile_zero;
    logic [$clog2(DEPTH)-1:0]      abase_zero;
    assign tile_zero  = '0;
    assign abase_zero = '0;

    axi_lite_ctrl #(
        .VEC_W(VEC_W), .SCALE_WIDTH(SCALE_WIDTH), .SHIFT_WIDTH(SHIFT_WIDTH)
    ) u_ctrl (
        .s_axi_aclk      (s_axi_aclk),
        .s_axi_aresetn   (s_axi_aresetn),
        .s_axi_awvalid   (s_axi_awvalid),
        .s_axi_awready   (s_axi_awready),
        .s_axi_awaddr    (s_axi_awaddr),
        .s_axi_wvalid    (s_axi_wvalid),
        .s_axi_wready    (s_axi_wready),
        .s_axi_wdata     (s_axi_wdata),
        .s_axi_wstrb     (s_axi_wstrb),
        .s_axi_bvalid    (s_axi_bvalid),
        .s_axi_bready    (s_axi_bready),
        .s_axi_bresp     (s_axi_bresp),
        .s_axi_arvalid   (s_axi_arvalid),
        .s_axi_arready   (s_axi_arready),
        .s_axi_araddr    (s_axi_araddr),
        .s_axi_rvalid    (s_axi_rvalid),
        .s_axi_rready    (s_axi_rready),
        .s_axi_rdata     (s_axi_rdata),
        .s_axi_rresp     (s_axi_rresp),
        .core_clk        (core_clk),
        .core_rst_n      (core_rst_n),
        .core_go         (core_go),
        .core_busy       (core_busy),
        .core_n_vecs     (core_n_vecs),
        .core_relu_en    (core_relu_en),
        .core_scale_mult (core_scale_mult),
        .core_shift_amt  (core_shift_amt),
        .core_perf_addr  (core_perf_addr),
        .core_perf_data  (core_perf_data)
    );

    ws_quant_unit #(
        .N(N), .K(K), .DATA_WIDTH(DATA_WIDTH), .ACC_WIDTH(ACC_WIDTH),
        .DEPTH(DEPTH), .VEC_W(VEC_W), .OUT_WIDTH(OUT_WIDTH),
        .SCALE_WIDTH(SCALE_WIDTH), .SHIFT_WIDTH(SHIFT_WIDTH)
    ) u_core (
        .clk        (core_clk),
        .rst_n      (core_rst_n),
        .go         (core_go),
        .w_tile_idx (tile_zero),
        .a_base     (abase_zero),
        .n_vecs     (core_n_vecs),
        .busy       (core_busy),
        .perf_clear (perf_clear),
        .perf_addr  (core_perf_addr),
        .perf_data  (core_perf_data),
        .wr_en_w    (wr_en_w),
        .wr_addr_w  (wr_addr_w),
        .wr_data_w  (wr_data_w),
        .wr_en_a    (wr_en_a),
        .wr_addr_a  (wr_addr_a),
        .wr_data_a  (wr_data_a),
        .sum_out    (sum_out),
        .sum_valid  (sum_valid),
        .q8_out     (q8_out),
        .q8_valid   (q8_valid),
        .relu_en    (core_relu_en),
        .scale_mult (core_scale_mult),
        .shift_amt  (core_shift_amt)
    );

endmodule
```
